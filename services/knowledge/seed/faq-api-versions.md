title: "Which API version should I use?"
tags: api, version, v1, v2, deprecation, migration
---
Use API v2. API v1 is deprecated and will be switched off on 30 June 2027. The main changes are
cursor-based pagination and ISO 8601 timestamps; see the v1-to-v2 migration guide in the docs.
